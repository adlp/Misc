# OpenWrt

Scripts et sous-projets pour routeurs OpenWrt.

## Sous-projets

- **OpenVpn/** — serveur OpenVPN sous OpenWrt (auth, client-connect, GeoIP IMAP Europe)
- **scripts/** — scripts UCI/firewall autonomes
  - `uciRuleFromName` — (dés)active une règle firewall UCI par son nom (list/get/set/toggle)
